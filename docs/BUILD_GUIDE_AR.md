# دليل بناء واختبار الجزء الرابع — التمام اليومي

**هذه حزمة مصدرية 0.0.4 وليست إصدارًا إنتاجيًا.**

1. فك ضغط `Altamam_AlYawmi_Part_IV_GitHub_Source.zip` وارفع الملفات والمجلدات **بمحتواها** إلى جذر مستودع `Win-manger` الخاص على `main`، واستبدل الملفات القديمة. احرص على نقل المجلد المخفي `.github`.
2. افتح GitHub → Actions → Windows foundation build. يجب أن يبدأ بناء جديد بعد رفع الشفرة.
3. تحقّق من نجاح `Validate Part III + Part IV SQLite business integrity` ويشمل 58 اختبارًا بلغة Python على SQLite داخل الذاكرة.
4. انتظر نجاح `Static analysis`, `Unit and widget tests`, و`Build Windows release`؛ اختبارات Dart الجديدة تنفذ على GitHub ولم يتيسر تنفيذها محليًا هنا.
5. خطوة `Show dependency cache status` تعرض إعادة استخدام كاش Flutter SDK وDart Pub؛ ظهور `cache miss` لا يعني فشل البناء.
6. حمّل Artifact باسم `Altamam_AlYawmi_Part_IV_Windows_x64`، ثم استخرج ملف ZIP الداخلي **مع جميع DLL وdata**. لا تنقل ملف exe بمفرده.
7. شغّل `التمام اليومي.exe` على Windows وتحقق من ظهور عنوان «الجزء الرابع — قواعد العمل وسلامة البيانات» وأن نافذة البرنامج تعمل بصورة طبيعية.
8. إذا نجح GitHub أرسل صورة Summary. وإذا ظهرت خطوة باللون الأحمر، افتحها وأرسل كامل الرسالة حتى أصلح الخلل داخل نفس النسخة.

**يجب التوقف بعد هذه المرحلة حتى نجاح الاختبار.** قاعدة البيانات التشغيلية المؤمنة، تسجيل الدخول وشاشات التحضير والأرشيف الفعلية ضمن المراحل الهندسية المقررة لاحقًا، ولا تُستخدم هذه النسخة لإدخال بيانات حقيقية.
