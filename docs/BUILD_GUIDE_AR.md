# إرشادات اختبار المرحلة 00 من GitHub

**الهدف:** إثبات أن مستودع Flutter يستطيع إنشاء تطبيق Windows فعلي، وليس إثبات اكتمال وظائف الإدارة.

1. فكّ الملف المضغوط على جهازك.
2. أنشئ مستودع GitHub **Private** باسم `adwas-personnel-windows`.
3. ارفع محتويات المجلد كلها بما فيها المجلد المخفي `.github`. تأكد أن `pubspec.yaml` موجود في جذر المستودع لا داخل مجلد فرعي.
4. افتح تبويب **Actions** ثم **Windows foundation build** واختر **Run workflow**.
5. يجب أن تنتهي مهمة `Analyze, test and build (Windows)` بعلامة نجاح خضراء.
6. من أسفل صفحة المهمة ضمن **Artifacts** حمّل الحزمة الناتجة.
7. افتح الحزمة الناتجة، ثم افتح ملف ZIP الداخلي واستخرج محتوياته كاملة في مجلد واحد على جهاز Windows.
8. شغّل `adwas_personnel.exe`. ينبغي أن تظهر شاشة تأسيس باللغة العربية، بدون ادعاء وجود تحضير أو قاعدة بيانات أو تسجيل دخول.
9. أغلق التطبيق وشغله مجددًا، وجرّب تغيير حجم النافذة.
10. **لا تنتقل إلى المرحلة 01 قبل إرسال نتيجة الاختبار في المحادثة.** إذا فشل البناء انسخ نص الخطوة الحمراء من Actions أو أرسل صورتها.

ملاحظتان: GitHub لا يفكّ ملف ZIP المرفوع إلى المستودع تلقائيًا. يجب رفع **ملفات المشروع المفكوكة** باستخدام Git أو طريقة تدعم المجلدات المخفية. لا تضع كشوف الأفراد أو ملفات قواعد البيانات في GitHub.
